What happens in the video

We open an ACIArena debate where three agents argue a medical question and a fourth aggregates their answers. One debater, Debater 0, has been prompted to argue for a wrong answer. We replay the run and use the Influence and Echo views to see who read and repeated whom. Then we fork at Debater 0's first message, replace only its prompt, and continue the run with CrewAI: the team's final answer changes from (B) to (A). After that we open a saved MAST report from another debate in the same benchmark, show how plugins are written, flag moments with comments, and watch a run stream in live. It's a tour of the tool, not a benchmark.

RESEARCH

Why we
built it.

Most evals grade each agent's final answer. We wanted to see the conversation in between.

Who read what? Who started repeating whom? Where did a bad idea first show up? Swarm Lens doesn't answer those for you. It gives you the trace, where each message came from, and a way to rerun the experiment with one thing changed.

GET STARTED

Run it on
your own machine.

You need Python 3.11+ and Git. Replaying a trace
doesn't call a model, so no API key yet.

Install and run
git clone https://github.com/agencyenterprise/fractal_swarm_lens.git
cd fractal_swarm_lens
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[web]'
swarm-lens --data data --port 8765

Then bring in a conversation.

Open localhost:8765, choose ⋯ → Import trace, and paste a transcript.

Want the medical debate from the demo, or to record a live CrewAI run? The docs have a recipe for each.
